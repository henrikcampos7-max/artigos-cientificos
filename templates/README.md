# Modelos

- `PROTOCOLO_ARTIGO.md`: planejamento antes da redação.
- `DECLARACAO_USO_IA.md`: registro interno e texto adaptável à revista.
- `MATRIZ_ALEGACAO_FONTE.csv`: rastreabilidade entre afirmações e evidência.
- `metadata-artigo.example.json`: metadados mínimos para um artigo no repositório.

Os campos entre colchetes devem ser preenchidos por pessoas responsáveis. Um modelo preenchido não comprova que a etapa foi executada.
