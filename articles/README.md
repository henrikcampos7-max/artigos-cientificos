# Artigos

Este diretório recebe apenas artigos cuja inclusão pública tenha sido aprovada pela governança científica.

Cada artigo deve usar `articles/<slug>/` e incluir, no mínimo:

- `metadata.json` conforme `templates/metadata-artigo.example.json`;
- README com status e responsáveis;
- protocolo e estratégia de busca aplicáveis;
- matriz de evidência e registro de revisão humana;
- informação de licença antes de qualquer PDF/DOCX.

Rascunhos não validados, dados de pacientes, pareceres confidenciais e material de terceiros não devem ser adicionados.
