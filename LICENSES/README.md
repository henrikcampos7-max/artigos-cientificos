# Licenças e direitos

Este repositório não aplica uma licença única a artigos, PDFs ou DOCX.

- Código e documentação precisam de decisão de licença explícita do proprietário antes de reutilização externa.
- Cada publicação deve registrar sua própria licença, DOI, versão e fonte.
- Coautoria não garante, por si só, direito de redistribuir o PDF editorial.
- Material de terceiros permanece fora do Git quando a licença não estiver confirmada.
- Quando o arquivo não puder ser redistribuído, publique somente citação, metadados e link oficial.

Antes de adicionar um binário, registre em `metadata.json`:

- titular dos direitos;
- licença e URL;
- versão do manuscrito;
- permissão de repositório/preprint;
- data e responsável pela verificação.
